UISI PrintMaster
================

Как запустить
-------------
1. Полностью распакуйте архив в отдельную папку.
2. Запустите файл "UISI PrintMaster.exe".
3. Подключите принтер или МФУ и убедитесь, что для него установлен драйвер Windows.

Что уже включено
----------------
- Среда .NET включена в эту переносимую сборку.
- Для запуска не нужны права администратора или установка программы.
- PDF и обычные текстовые файлы печатаются встроенными средствами приложения.

Дополнительные компоненты
-------------------------
- Для точного предпросмотра, печати и преобразования DOCX нужен Microsoft Word.
- Для предпросмотра PDF и преобразования текстовых файлов нужен Microsoft Edge
  WebView2 Runtime. Обычно он уже установлен в Windows 10 и Windows 11.
- Для сканирования и печати нужен штатный драйвер конкретного принтера или МФУ.

Важно
-----
- Не запускайте программу прямо из ZIP-архива.
- Windows SmartScreen может показать предупреждение для неподписанного приложения.
  Запускайте файл только если архив получен из доверенного источника.
